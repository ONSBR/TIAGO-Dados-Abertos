# Código de Conduta

Este projeto adota o [Contributor Covenant](https://www.contributor-covenant.org/),
versão 2.1.

Em resumo: trate as pessoas com respeito. Crítica técnica é bem-vinda e necessária.
Ataque pessoal, assédio e desprezo não são. Discordar de uma decisão técnica é
contribuição; humilhar quem a tomou não é.

Comportamento inaceitável pode ser reportado em privado aos mantenedores, pelos contatos
da organização [ONSBR](https://github.com/ONSBR) no GitHub. Toda queixa é analisada e
respondida. O canal de vulnerabilidade descrito em [SECURITY.md](SECURITY.md) não serve
para isso.

Texto completo: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
